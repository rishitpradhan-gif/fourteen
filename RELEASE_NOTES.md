# v0.1.0 — theorem and reproducibility release

A sharp fourteen-ply obstruction to universally legal fixed first-player matching policies on every odd Connect Four board with width and height at least five. Includes a constructive attack, paired-path coloring checks, and an independent shortest-win search of a sharpness example.

Read PROOFS.md for the full hypotheses and proofs, evidence/ for reproducible results, and PROVENANCE.md and REFERENCES.md for attribution and priority status. Python standard library only. Worldwide novelty is not asserted.
